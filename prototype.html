二、流程图

1. 用户下载流程

flowchart TD A[用户访问主页 / 任一平台落地页] --> B[粘贴视频 URL] B --> C[点击 Download] C --> D[前端 fetch 发送 POST /download] D --> E{服务端 URL 校验
协议 + 域名白名单} E -- 非法/不在白名单 --> E1[返回 400
前端浮层提示错误] E -- 合法 --> F[run_in_threadpool 调 downloader] F --> G[yt-dlp extract_info 解析并下载
输出到 downloads/] G --> H[返回 title / thumbnail / download_url] H --> I[前端渲染结果卡片] I --> J[用户点击 下载视频] J --> K[浏览器请求 /downloads/xxx.mp4] K --> L[StaticFiles 静态服务返回文件
触发浏览器下载] E1 --> M[结束] L --> M

3. 下载文件生命周期（时序）

sequenceDiagram participant U as 用户 participant FE as 前端页面 participant API as /download API participant DL as downloader.py participant YT as yt-dlp participant FS as downloads/ 存储 U->>FE: 输入 URL 并点击下载 FE->>API: POST /download {url} API->>DL: run_in_threadpool(get_video_info) DL->>YT: extract_info(url, download=True) YT->>FS: 下载视频文件 (uuid.mp4) YT-->>DL: 返回元数据 DL-->>API: {title, thumbnail, download_url} API-->>FE: 200 {success:true, ...} FE-->>U: 渲染结果卡片 U->>FS: 点击下载 → GET /downloads/uuid.mp4 Note over FS: 超过保留期(默认24h)
